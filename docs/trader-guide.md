# 모의투자 실행기 사용법

## 1. 연습 모드로 먼저 돌려보기 (키움 없이)
```
python scripts/run_trader.py --check     # 주문 계획만 보기
python scripts/run_trader.py             # 가상 계좌(1만 달러)로 실제처럼 기록
```
결과는 `paper/` 폴더에 쌓입니다.

## 2. 키움 모의투자로 실행
```
python scripts/run_trader.py --mode kiwoom --check   # 잔고·예수금만 조회하고 주문 계획 출력
python scripts/run_trader.py --mode kiwoom           # 실제 모의 주문
```
- `--check`는 주문을 내지 않고 잔고(ust21070)와 예수금(ust21160)만 읽습니다. 처음엔 꼭 이것부터 실행하세요.
- 주문은 지정가(ust20000 매수, ust20001 매도)로 나갑니다. 키움 모의투자는 시장가를 받지 않아서, 매수는 현재가보다 1.5% 높게, 매도는 1.5% 낮게 값을 불러 바로 체결되게 합니다. 미국장이 열려 있을 때만 체결됩니다.
- 키움은 주문을 받기만 하고 체결은 나중에 되므로 `trades.jsonl`에는 `pending`으로 기록됩니다. 다음 실행 때 잔고에서 실제 보유수량을 다시 읽습니다.
- 매도 대금이 아직 정산 전이라 같은 날 매수가 "예수금 부족"으로 거부될 수 있습니다. 그러면 그달 리밸런싱이 끝나지 않은 것으로 남고, 다음 날 실행 때 부족한 만큼만 다시 주문합니다.

## 3. Mintory 앱 (더블클릭 한 번)
`mintory.bat`(또는 바탕화면 Mintory 아이콘)을 열면 세 가지가 일어납니다.
1. 창 없이 뒤에서 도는 **자동 실행기**가 켜집니다(이미 켜져 있으면 그대로).
2. Mintory 창이 열리고, 키움 모의계좌 잔고를 새로 읽어 화면을 갱신합니다. 이때는 주문을 절대 내지 않습니다.
3. 윈도우를 켤 때 자동 실행기가 저절로 켜지도록 등록합니다.

화면 오른쪽 위 버튼:
- **잔고 새로고침**: 키움 모의계좌 잔고를 다시 읽습니다. 주문은 내지 않습니다.
- **지금 매매 실행**: 밤 11시 45분 자동 실행과 같은 작업을 지금 한 번 합니다. 확인창이 먼저 뜨고, 미국장이 닫혀 있으면 그 안내도 보여줍니다.
- **일시정지 / 다시 시작**: 일시정지하면 그 뒤로 주문을 내지 않습니다(자동 실행 포함). 화면에 빨간 "일시정지됨" 표시가 뜹니다.

화면은 자동 실행기가 `http://127.0.0.1:47321` 에서 보여줍니다. 이 주소는 내 PC 안에서만 열리고, 다른 웹사이트가 버튼을 대신 누를 수 없게 막혀 있습니다.

## 4. 매일 자동 실행 (앱이 알아서)
- 자동 실행기는 **한국시간 월~금 밤 11시 45분**에 모의투자를 실행합니다. 미국장은 밤 10시 30분(서머타임) 또는 11시 30분에 열리므로 두 경우 모두 장중입니다.
- 기본 전략(2026-10-10부터)은 **EEM 카나리아 + 4분할**입니다. 돈을 4덩어리로 나눠 월말, +5, +10, +15거래일에 한 덩어리씩 리밸런싱하므로 한 달에 최대 4번 주문합니다. 리밸런싱 날 신흥국 ETF(EEM)의 모멘텀이 0 이하면 그 덩어리는 전부 IEF(중기 국채)로 피합니다. 목표가 바뀐 날에만 주문하고, 나머지 날은 평가금액을 기록하고 대시보드를 새로 만듭니다.
- 예전 전략(월 1회 멀티기간 모멘텀)은 `--strategy multi`로 쓸 수 있습니다.
- 전략이 바뀌면 첫 실행 때 이전 기록(`trades.jsonl`, `equity.jsonl`, `meta.json`)을 `paper/archive/<이전 전략>_<날짜>/`로 옮기고 그날부터 수익률을 새로 셉니다. 보유 종목은 그대로 두고 새 목표와 차이나는 만큼만 사고팝니다.
- 11시 45분에 PC가 꺼져 있었더라도 새벽 5시 전에 켜면 바로 실행합니다. 그보다 늦으면 다음 날 실행에서 밀린 리밸런싱을 처리합니다.
- 상태는 `paper/agent.json`(다음 실행 시각, 마지막 결과), 기록은 `paper/logs/agent.log`에 남습니다.
- 다음 실행 시각 확인: `python scripts/mintory_agent.py --status`
- 윈도우 시작 시 자동 실행 해제: `python scripts/mintory_agent.py --uninstall-startup`

## 5. 업데이트 (update.bat 더블클릭)
`update.bat`을 더블클릭하면 GitHub의 최신 코드를 받아 이 폴더에 덮어씁니다. ZIP을 받아 `.env`와 `paper` 폴더를 옮겨 붙일 필요가 없습니다.
- `.env`, `paper/`(매매 기록), `reports/`, `data_cache/`는 건드리지 않습니다.
- 처음 한 번은 GitHub 읽기 전용 토큰이 필요합니다. 없으면 만드는 방법이 화면에 나오고 GitHub 페이지가 열립니다. 만든 토큰은 `.env`에 `GITHUB_TOKEN=...` 한 줄로 넣습니다.
- 자동 실행기가 매매 중이면 업데이트하지 않습니다. 켜져 있으면 1분 안에 새 코드로 스스로 다시 켜집니다.
- 새 버전이 있는지만 보기: `python scripts/update.py --check`

## 6. 긴급 정지
Mintory 화면의 **일시정지** 버튼을 누르세요. 화면을 열 수 없을 때는 `paper` 폴더에 `STOP`이라는 이름의 빈 파일을 만들어도 똑같습니다. 파일을 지우면(또는 다시 시작 버튼) 다시 동작합니다.

## 안전장치
- 주문 하나가 계좌 전체 금액보다 크면 막습니다. 가격이나 단위가 잘못 계산됐을 때를 대비한 것입니다. 금액으로 고정하고 싶으면 `TraderConfig.max_order_usd`에 달러 금액을 넣으세요.
- 50달러 미만의 자잘한 조정 주문은 건너뜁니다.
- 현금 2%는 수수료와 가격 변동에 대비해 남겨둡니다.
- 같은 달에는 리밸런싱을 한 번만 합니다. 주문이 하나라도 실패하면 다음 실행 때 다시 시도합니다.
